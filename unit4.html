1. Introduction: What does the processor do with numbers?

The microprocessor understands only one language: binary numbers (bits 0/1). However, it can perform arithmetic operations (addition, subtraction, multiplication, division) and logic operations (AND, OR, XOR, shift, rotate). All these operations are executed inside a unit called the ALU (Arithmetic Logic Unit).

💡 Today we will see how to write assembly programs that use these operations, and most importantly: how the processor tells us the result through the Flags Register.

2. Flags Register – The processor's traffic lights

It is a bit register (16‑bit or 32‑bit) where each bit represents a "flag" that shows the state after an operation. The four main flags we use:

FlagNameWhen = 1?Example (8-bit)
CFCarry FlagCarry out of MSB in addition, or borrow in subtraction0xFF + 1 = 0x00 → CF=1
ZFZero FlagResult is zero5 - 5 = 0 → ZF=1
SFSign FlagResult is negative (MSB = 1 in signed)0x80 (-128) → SF=1
OFOverflow FlagSigned overflow (result out of signed range)127 + 1 = -128 → OF=1

Reminder: Signed 8‑bit range: -128 … 127 ; Unsigned 8‑bit range: 0 … 255.

3. Arithmetic Operations

Addition & Subtraction

InstrMeaningFlags affected
ADD dest, srcdest = dest + srcCF, ZF, SF, OF
SUB dest, srcdest = dest - srcCF, ZF, SF, OF
INC destdest = dest + 1ZF, SF, OF (CF unchanged)
DEC destdest = dest - 1ZF, SF, OF (CF unchanged)
ADC / SBBAdd/Subtract with carry/borrowCF, ZF, SF, OF
Example (Carry): AL = 0xFE (254), BL = 0x05 → ADD AL, BL → AL = 0x03, CF=1 because 254+5>255.
Example (Overflow): MOV AL, 127; ADD AL, 1 → AL = 128, OF=1 (signed overflow), CF=0.

Multiplication MUL / IMUL

Byte operand: AL * src → AX . Word operand: AX * src → DX:AX. CF/OF set if upper half ≠ 0.

MOV AL, 5
MOV BL, 3
MUL BL      ; AX = 15 (0x000F), CF=0

Division DIV / IDIV

Byte: AX / src → AL (quotient), AH (remainder). Word: DX:AX / src → AX (quotient), DX (remainder). ⚠️ Division by zero or quotient overflow → interrupt 0.

MOV AX, 25
MOV BL, 4
DIV BL      ; AL = 6, AH = 1

7. Number Base Conversion using Logic Ops

Binary ↔ Hexadecimal

Every 4 bits = one hex digit. Extract nibbles using AND and SHR.

; Convert byte in AL to two hex digits (nibbles)
MOV BL, AL
AND BL, 0x0F       ; low nibble
SHR AL, 4          ; high nibble
; then convert each nibble to ASCII (0-9,A-F)

Decimal → Binary (print bits)

MOV CX, 8
print_bit:
    SHL AL, 1      ; shift MSB into CF
    JC  print_one
    ; else print '0'
    ...

9. Summary and Quick Review

  • Flags Register (CF, ZF, SF, OF) tells the state after every operation.
  • ADD/SUB set flags according to the result; MUL/DIV use implicit registers (AX, DX:AX).
  • Logic ops (AND, OR, XOR, NOT) work per bit — ideal for masking, setting, toggling.
  • Shifts & rotates move bits, affect CF, and can multiply/divide by powers of two.
  • Conditional jumps (JE, JA, JG, etc.) enable decision making. Use CMP then the appropriate jump.
  • Base conversion can be done with repeated division (decimal) or shifts/masks (binary/hex).
  • The calculator project ties everything together: I/O, arithmetic, flags, jumps, and display.
