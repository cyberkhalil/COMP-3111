1. Strings & The Role of the OS

A string in assembly is simply a sequence of bytes in memory, often terminated by a null (0). The operating system provides services like:

  • Keyboard input
  • Screen output
  • File handling
  • Message boxes
💡 The Irvine32 library wraps these OS services into easy‑to‑use functions for assembly programmers.

2. String Primitives (MOVSB, STOSB, LODSB, CMPSB)

These instructions operate on memory blocks using ESI (source), EDI (destination) and ECX (counter).

InstructionOperationDirection effect
MOVSBMove byte from [ESI] → [EDI]ESI/EDI ± 1
STOSBStore AL → [EDI]EDI ± 1
LODSBLoad [ESI] → ALESI ± 1
CMPSBCompare byte [ESI] with [EDI]ESI/EDI ± 1

Repeat prefixes: REP, REPE, REPNE – repeat ECX times or while condition holds.

; Copy a 5-byte string
mov esi, OFFSET source
mov edi, OFFSET dest
mov ecx, 5
cld               ; clear direction flag (forward)
rep movsb

4. File Operations in Irvine32

FunctionDescription
CreateOutputFileEDX = filename → returns handle in EAX
OpenFileOpen existing file (read mode)
WriteToFileEAX=handle, EDX=data, ECX=bytes → writes data
ReadFromFileRead from file into memory
CloseFileEAX=handle → close
 
; Write a string to a file
.data
    fname db "output.txt",0
    content db "Hello File!",0
.code
    mov edx, OFFSET fname
    call CreateOutputFile
    mov ebx, eax          ; save handle
    mov edx, OFFSET content
    mov ecx, LENGTHOF content
    call WriteToFile
    mov eax, ebx
    call CloseFile

5. Windows API from Assembly

API functions expect parameters on the stack (pushed right‑to‑left) and follow the stdcall convention.

; ExitProcess
push 0
call ExitProcess

; MessageBoxA (requires user32.lib)
push 0          ; MB_OK
push OFFSET caption
push OFFSET message
push 0          ; parent window
call MessageBoxA
ℹ️ When using Irvine32, many API functions are already linked. You can also use INVOKE for safer calls.

7. Summary

  • String primitives (MOVSB, STOSB, LODSB, CMPSB) move and compare blocks of memory efficiently.
  • Irvine32 library provides easy‑to‑use console I/O (WriteString, ReadString, WriteInt, etc.).
  • File functions (CreateOutputFile, WriteToFile, ...) allow persistent storage.
  • Windows API can be called directly (stack + call) for advanced features like message boxes.
  • The XOR cipher menu ties everything together: input, processing, output, and conditional logic.
