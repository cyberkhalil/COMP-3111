Unit 3: Data Movement & Addressing Modes

Introduction

In assembly language, the programmer directly controls how data moves between registers and memory. Unlike high-level languages, nothing is automatic — every movement must be explicitly defined.

This unit focuses on memory access, pointers, arrays, and how the CPU calculates addresses.

MOV Instruction

MOV EAX, 5
MOV EBX, EAX
  • MOV copies data from source to destination
  • Does NOT modify source
  • Fundamental instruction in assembly

Addressing Modes

Mode Example
Immediate MOV EAX, 10
Register MOV EAX, EBX
Direct Memory MOV EAX, num
Indirect MOV AL, [ESI]
Indexed MOV AL, [ESI+2]
Addressing modes define how CPU calculates the memory location of data.

Pointers

A pointer stores a memory address instead of a value.

MOV ESI, OFFSET value
MOV EAX, [ESI]
  • ESI → address
  • [ESI] → value at that address

Arrays in Memory

numbers DB 1,2,3,4,5

Arrays are stored in consecutive memory locations.

Each element is located next to the previous one in memory.

Traversing Arrays

MOV ESI, OFFSET array
MOV ECX, 5

Next:
MOV AL, [ESI]
INC ESI
LOOP Next
  • ESI moves through memory
  • ECX controls loop count

Reversing Arrays

Two pointers are used:

  • ESI → start
  • EDI → end
MOV AL, [ESI]
MOV BL, [EDI]

MOV [ESI], BL
MOV [EDI], AL
