Why Learn Assembly?

Assembly gives you x‑ray vision into the processor. Every high‑level instruction (if, for) becomes a chain of moves, compares, and jumps. As a cybersecurity engineer, you will use this to:

  • 🔬 Analyze malware at the hardware level
  • 🧱 Spot memory and stack vulnerabilities
  • 🛠️ Write tiny, efficient programs
  • 📊 See exactly how the CPU reacts to every instruction
💡 emu8086 is your visual lab – it shows the processor, registers, and memory like an interactive electronic board.

The 8086 Processor – A Visual Metaphor

Think of the CPU as a tiny office. The registers are like special sticky notes that hold numbers while the processor works. The 8086 has 16‑bit registers (they can store values up to 65535).

The Four Main Helpers (General‑Purpose Registers)

AX – Calculator (Accumulator)
Main place for arithmetic: +, -, *, /
BX – Path (Base)
Often holds a memory address
CX – Counter
Loop “prayer beads” – counts repetitions
DX – Storage (Data)
Extra space for big data or I/O

📌 Each register splits into high/low 8‑bit parts: AH/AL, BH/BL, etc.

Segment Registers & Pointers (“GPS” of the CPU)

  • 📂 CS, DS, SS, ES – define memory segments (code, data, stack).
  • 📍 IP – Instruction Pointer (next instruction).
  • 📌 SP, BP, SI, DI – navigate stack and arrays.

Flags – The Processor’s Status Lights

  • ZF (Zero) – lights up if result = 0
  • SF (Sign) – high bit; 1 = negative
  • CF (Carry) – carry out / borrow
  • OF (Overflow) – signed result doesn’t fit
👀 In the emulator, watch these flags update live after each instruction.

Assembly → Machine Code → Circuits

Take the simple instruction:

MOV AX, 5

The assembler turns it into opcode B8 followed by two bytes for 5. The processor then:

  1. 📥 Fetches the opcode from memory (address in IP).
  2. 🧠 Control Unit decodes: “move immediate to AX”.
  3. 🔗 Sends the value 5 through the internal data bus into AX.
  4. ✅ AX updates – you see it in the emulator!

First Instructions & Flag Watching

🔹 MOV (Data Transfer)

MOV AL, 10
MOV BL, 20
MOV CL, AL    ; CL = 10

Step through with F7 and watch AL, BL, CL change.

🔹 ADD and Overflow

MOV AL, 100
ADD AL, 200   ; 100+200=300, AL=44 (300-256), CF=1, OF=1

After ADD: CF=1 (carry out), OF=1 (overflow), ZF=0, SF=0.

🔹 SUB and Zero Flag

MOV AL, 5
SUB AL, 5     ; AL = 0 → ZF = 1

Zero flag becomes 1 – used for conditional jumps.

Control Flow: Jumps & Loops

🔹 Compare & Conditional Jumps

MOV AL, 10
CMP AL, 10   ; virtual subtraction, ZF=1
JE  label1   ; jump if equal (ZF=1)
JNE label2   ; jump if not equal (ZF=0)

JE = JZ – both check the Zero flag.

🔹 LOOP Instruction

MOV CX, 5
loop_start:
    ; body
    LOOP loop_start   ; CX--, if CX ≠ 0 jump

🖨️ Example: Print digits 5→1 (emu8086 DOS interrupt)

MOV CX, 5
MOV AH, 2
MOV DL, '5'
print_loop:
    INT 21h
    DEC DL
    LOOP print_loop

Hands‑On Lab: Find the Maximum Number (Treasure Hunt!)

Instead of a complex sorting algorithm, we’ll hunt for the largest value in an array – one simple loop, clear concepts.

  • 🔹 One single loop (no nesting)
  • 🔹 Array traversal, comparison, conditional jump
  • 🔹 Flags observed step‑by‑step

🔹 The Plan

  1. Store a list of numbers in memory.
  2. Assume the first element is the maximum (put it in AL).
  3. Loop through the rest, comparing with CMP.
  4. If a larger number is found (JAE skip otherwise), update AL.
  5. At the end, AL holds the maximum.

📋 Complete Code (emu8086)

.model small
.data
    arr   db 12, 7, 25, 9, 18, 3
    count db 6
.code
main:
    mov ax, @data
    mov ds, ax

    mov cl, count
    dec cl
    mov si, offset arr
    mov al, [si]      ; first element as max
    inc si            ; point to second element

search_loop:
    cmp al, [si]      ; compare max with next
    jae not_bigger    ; if AL >= [SI], skip
    mov al, [si]      ; else update max
not_bigger:
    inc si
    dec cl
    jnz search_loop   ; repeat

    ; AL now has the maximum value

    mov ah, 4ch
    int 21h
end main

🔎 Flag Observation

  • Use F7 to step through.
  • After each CMP, watch CF: if AL is below [SI], CF=1, so JAE will not jump and we update AL.
  • Watch AL change only when a bigger number appears.
💡 The treasure is the largest number – you’ve just found it without sorting!
