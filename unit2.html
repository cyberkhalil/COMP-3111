From C to Assembly – A Peek Under the Hood

Take this simple C code:

int a = 10;
int b = 20;
if (a > b) {
    a = a + 1;
} else {
    b = b - 1;
}

A compiler (roughly) turns it into:

mov eax, [a]
cmp eax, [b]
jle else_block
inc a
jmp end_if
else_block:
dec b
end_if:
💡 Notice: if (a > b) is reversed to jle (jump if less or equal) to skip the if‑body. Loops (for, while) work similarly with labels and conditional jumps.

Structure of a MASM Program (32‑bit)

.586
.model flat, stdcall
.stack 4096

.data
    message db "Hello, Assembly!", 0
    sum     DWORD 0

.code
main PROC
    mov eax, 5
    add eax, 10
    mov sum, eax

    INVOKE ExitProcess, 0
main ENDP
END main
  • .data holds initialised variables.
  • .code contains procedures.
  • main PROC … main ENDP defines the entry point.
  • INVOKE calls Windows API functions (e.g., ExitProcess).

Basic Instructions Cheat Sheet

Instruction Example Effect
MOV mov eax, 10 EAX = 10
ADD add eax, 5 EAX = EAX + 5
SUB sub eax, 2 EAX = EAX – 2
INC inc eax EAX = EAX + 1
DEC dec eax EAX = EAX – 1

Setting Up MASM + Visual Studio Code

  1. 📥 Download & install MASM32 SDK from masm32.com.
  2. 📁 Add C:\masm32\bin to your system PATH.
  3. 📝 In VS Code, create a .asm file.
  4. ⚙️ Assemble & link: 
    ml /c /coff /Zi program.asm
link /SUBSYSTEM:CONSOLE /DEBUG program.obj
  5. ▶️ Run program.exe or debug with x64dbg / WinDbg.

Lab Exercise (Hardcoded Values – Main Task)

Write a program that adds three integers and stores the result – then trace it in a debugger.

Use fixed (hardcoded) numbers so you can focus on how the instructions work.

📋 Complete Code (MASM 32‑bit)

.586
.model flat, stdcall
.stack 4096

.data
    num1 DWORD 10
    num2 DWORD 20
    num3 DWORD 30
    sum  DWORD ?

.code
main PROC
    mov eax, num1      ; EAX = 10
    add eax, num2      ; EAX = 10 + 20 = 30
    add eax, num3      ; EAX = 30 + 30 = 60
    mov sum, eax       ; store the result

    ; exit gracefully
    mov eax, 0
    ret
main ENDP
END main

🔎 Debugging Steps (x64dbg / WinDbg)

  • Assemble with debugging info (/Zi).
  • Open the .exe in your debugger.
  • Set a breakpoint at main.
  • Step through (F8) and watch EAX change after each ADD.
  • After mov sum, eax, inspect the memory location of sum (should contain 60 = 0x3C).

Bonus Challenge (User Input)

⭐ Bonus: Interactive Version

Once you understand the hardcoded version, extend the program to ask the user for three numbers, calculate the sum, and display it.

Hints (using MASM32 library):

include \masm32\include\masm32.inc
includelib \masm32\lib\masm32.lib

.data
    prompt db "Enter a number: ", 0
    input  db 11 dup(?)      ; buffer for input
    result db 11 dup(?)
.code
    INVOKE StdOut, ADDR prompt
    INVOKE StdIn, ADDR input, 10
    ; convert input string to integer, add, convert back, print...
