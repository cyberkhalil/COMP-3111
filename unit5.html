🔀 Control Flow · CMP, JMP, LOOP

CMP – Compare Two Operands

Compares two values and sets flags (ZF, SF, OF, CF) without modifying the operands.

CMP EAX, EBX   ; sets flags based on EAX – EBX

Conditional Jumps (based on flags)

JumpConditionMeaning
JE / JZZF = 1Equal / Zero
JNE / JNZZF = 0Not Equal / Not Zero
JG / JNLESF = OF and ZF = 0Greater (signed)
JL / JNGESF ≠ OFLess (signed)
JA / JNBECF = 0 and ZF = 0Above (unsigned)
JB / JNAECF = 1Below (unsigned)

JMP – Unconditional Jump

JMP label      ; always jumps to label

LOOP – Loop with ECX counter

Decrements ECX automatically. Jumps to label if ECX ≠ 0.

MOV ECX, 5
myLoop:
    ; instructions here
    LOOP myLoop   ; ECX-- and jump if ECX != 0
💡 Example: Sum numbers 1..10 using conditional jump 
MOV EAX, 0
MOV ECX, 10
sumLoop:
    ADD EAX, ECX
    LOOP sumLoop   ; ECX = 9,8,...,1,0 → stops

📚 The Stack in Action

The stack is a LIFO (Last-In-First-Out) memory region pointed to by ESP (stack pointer). It grows downward (towards lower addresses).

PUSH and POP

PUSH EAX        ; ESP -= 4, then [ESP] = EAX
POP  EBX        ; EBX = [ESP], then ESP += 4

PUSHAD / POPAD – Save/Restore all general registers

PUSHAD          ; pushes EAX,ECX,EDX,EBX,ESP,EBP,ESI,EDI
; ... some code that might change registers
POPAD           ; restores all registers
🔍 The stack is heavily used for:
  • Storing return addresses (by CALL)
  • Passing parameters to functions
  • Creating local variables
  • Saving register values before a call

📞 Procedures · CALL and RET

A procedure is a reusable block of code. Use CALL to jump to it, and RET to return.

main PROC
    CALL MyProcedure
    ; execution continues here after RET
MyProcedure PROC
    ; ... do something
    RET
MyProcedure ENDP

What happens inside?

  • CALL pushes the return address (next instruction) onto the stack.
  • RET pops that address and jumps back.

Passing Parameters via Registers (simple)

; Add two numbers (EAX, EBX) and return result in EAX
AddProc PROC
    ADD EAX, EBX
    RET
AddProc ENDP

; Calling it:
MOV EAX, 10
MOV EBX, 20
CALL AddProc   ; EAX = 30

🖼️ Stack Frames · Prologue & Epilogue

A stack frame is a fixed region on the stack dedicated to a single procedure call. It enables local variables and easy parameter access.

Standard Prologue

MyProc PROC
    push ebp           ; save caller's frame pointer
    mov  ebp, esp      ; set our own frame pointer

Standard Epilogue

    mov esp, ebp
    pop ebp
    ret
MyProc ENDP

After prologue, EBP becomes a stable reference to the stack frame:

  • [EBP+8] → first parameter (if any)
  • [EBP-4] → first local variable (after allocating space)
  • [EBP] → saved EBP
  • [EBP+4] → return address
🧠 Why use EBP? ESP changes when you push/pop, but EBP stays fixed throughout the procedure, making parameter and local variable access predictable.

🤝 Calling Conventions · cdecl / stdcall

Calling conventions define who cleans the stack and the order of parameters.

cdecl (default in C/C++)

  • Caller pushes parameters from right to left.
  • Caller cleans the stack after the call (add esp, param_bytes).
  • Allows variable number of arguments (like printf).
; Example: add(5, 3) using cdecl
push 3
push 5
call Add
add esp, 8      ; caller cleans 2 parameters (4 bytes each)

stdcall (used by Win32 API)

  • Caller pushes parameters from right to left.
  • Callee cleans the stack using ret n.
  • No variable arguments.
Add PROC
    mov eax, [ebp+8]   ; first param
    add eax, [ebp+12]  ; second param
    ret 8              ; return and pop 8 bytes (2 params)
Add ENDP
📌 In MASM, you can specify stdcall in the .model directive: .model flat, stdcall

📦 Local Variables

Reserve space on the stack by subtracting from ESP inside the prologue.

MyProc PROC
    push ebp
    mov  ebp, esp
    sub  esp, 8        ; allocate 8 bytes for two local variables (e.g., two DWORDs)

    ; access locals using [ebp-4], [ebp-8]
    mov dword ptr [ebp-4], 123   ; first local = 123
    mov eax, [ebp-4]             ; use it

    mov esp, ebp       ; deallocate locals
    pop ebp
    ret
MyProc ENDP

You can also use named constants for clarity:

local_a = -4
local_b = -8

🔁 Recursive Procedures

A recursive procedure calls itself. Each call creates a new stack frame. Too many recursive calls cause stack overflow.

Example: Factorial (n!) → n * (n-1)! with base case n=0 or n=1 returning 1.

Factorial PROC
    push ebp
    mov  ebp, esp
    mov  eax, [ebp+8]   ; parameter n

    cmp  eax, 1
    jle  base_case      ; if n <= 1 return 1

    dec  eax            ; n-1
    push eax
    call Factorial      ; recursive call (result in EAX)
    ; after return, multiply by original n
    mov  ecx, [ebp+8]   ; original n
    imul eax, ecx
    jmp  done

base_case:
    mov  eax, 1

done:
    mov esp, ebp
    pop ebp
    ret 4               ; stdcall: clean 1 parameter
Factorial ENDP
⚠️ Stack limit: Each recursive call uses about 12–16 bytes (return address, saved EBP, parameters). Too many calls (> 1 million in 32‑bit) crash the program.
