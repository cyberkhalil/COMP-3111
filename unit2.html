1. From C to Assembly – A Peek Under the Hood

Take this simple C code:

int a = 10;
int b = 20;
if (a > b) {
    a = a + 1;
} else {
    b = b - 1;
}

A compiler (roughly) turns it into:

mov eax, [a]
cmp eax, [b]
jle else_block
inc a
jmp end_if
else_block:
dec b
end_if:
💡 Notice: if (a > b) is reversed to jle (jump if less or equal) to skip the if‑body. Loops (for, while) work similarly with labels and conditional jumps.

2. Structure of a MASM Program (32‑bit)

.586
.model flat, stdcall
.stack 4096

.data
    message db "Hello, Assembly!", 0
    sum     DWORD 0

.code
main PROC
    mov eax, 5
    add eax, 10
    mov sum, eax

    INVOKE ExitProcess, 0
main ENDP
END main
  • .data holds initialised variables.
  • .code contains procedures.
  • main PROC … main ENDP defines the entry point.
  • INVOKE calls Windows API functions (e.g., ExitProcess).

3. Your First Program: "Hello, World!"

Using direct DOS interrupts (works under emulators like DOSBox, or in 32‑bit console with some adjustments). This is the classic way to print a string without Irvine32.

.model small
.stack 100h
.data
    msg db 'Hello, World!$'   ; $ is the string terminator for DOS
.code
main PROC
    mov ax, @data
    mov ds, ax
    mov dx, OFFSET msg
    mov ah, 9        ; DOS function to print string
    int 21h
    mov ah, 4Ch      ; DOS exit function
    int 21h
main ENDP
END main
💡 Explanation: int 21h is a software interrupt that calls DOS services. Service 9 prints a string, service 4Ch exits the program.

4. Addressing Modes: Immediate, Register, Direct

Mode Example Meaning
Immediate mov eax, 5 Constant value 5 is placed into EAX.
Register mov eax, ebx Copy contents of EBX into EAX.
Direct (memory) mov eax, [sum] Load from memory variable sum into EAX.

These patterns are the foundation of data movement in assembly.

5. Basic Instructions Cheat Sheet

Instruction Example Effect
MOV mov eax, 10 EAX = 10
ADD add eax, 5 EAX = EAX + 5
SUB sub eax, 2 EAX = EAX – 2
INC inc eax EAX = EAX + 1
DEC dec eax EAX = EAX – 1

6. Translating Loops (for, while)

C for-loop: for(i=0; i<10; i++) { sum = sum + i; }

Assembly translation (using ECX as counter):

    mov ecx, 0          ; i = 0
    mov eax, 0          ; sum = 0
for_loop:
    cmp ecx, 10
    jge end_for
    add eax, ecx
    inc ecx
    jmp for_loop
end_for:
    ; result in EAX

while loop example: while (x > 0) { x--; }

    mov eax, x
while_start:
    cmp eax, 0
    jle end_while
    dec eax
    jmp while_start
end_while:
🔁 Notice: conditional jump at the top (or bottom) controls the loop. The compiler often reverses the condition.

7. Setting Up MASM + Visual Studio Code

  1. 📥 Download & install MASM32 SDK from masm32.com.
  2. 📁 Add C:\masm32\bin to your system PATH.
  3. 📝 In VS Code, create a .asm file.
  4. ⚙️ Assemble & link: 
    ml /c /coff /Zi program.asm
link /SUBSYSTEM:CONSOLE /DEBUG program.obj
  5. ▶️ Run program.exe or debug with x64dbg / WinDbg.
