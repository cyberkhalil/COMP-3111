📦 Data Movement Instructions

MOV – Move Data

Copies data from source to destination. Source remains unchanged.

MOV EAX, 5        ; immediate → register
MOV EBX, EAX      ; register → register
MOV [1234h], ECX  ; register → memory

Rules: Same size for both operands. Cannot move memory → memory directly. Cannot move immediate → segment register directly.

MOVZX – Move with Zero‑Extension

Moves a smaller value to a larger destination and fills new bits with zeros (for unsigned numbers).

MOV AL, 0FFh
MOVZX EAX, AL     ; EAX = 0x000000FF = 255 (not -1)

MOVSX – Move with Sign‑Extension

Moves a smaller signed value to a larger destination and copies the sign bit.

MOV AL, 0FFh      ; -1 in signed
MOVSX EAX, AL     ; EAX = 0xFFFFFFFF = -1

LEA – Load Effective Address

Calculates the address (inside brackets) and stores it in a register. Does NOT access memory.

LEA EBX, [ESI+4]  ; EBX = ESI + 4  (address, not value)
🔍 Key difference: MOV EBX, [ESI] loads the value from memory.
LEA EBX, [ESI] loads the address (the pointer) itself.

📌 Operand Types

  • Immediate operand: A constant value written directly. Example: MOV EAX, 100
  • Register operand: A register name like AX, BX, ECX, DL. Example: MOV EBX, EAX
  • Memory operand: A location in memory, written inside square brackets [ ]. Example: MOV AL, [2000h]
; Quick comparison
MOV EAX, 42         ; 42 is immediate
MOV ECX, EAX        ; EAX and ECX are register operands
MOV [1000h], ECX    ; [1000h] is memory operand

🧭 Addressing Modes in Detail

Seven fundamental ways to specify a memory operand address:

Mode Example Explanation
Direct MOV AL, [2000h] Fixed address
Indirect MOV AL, [EBX] Address in a register
Indirect + Displacement MOV AL, [EBX+4] Register + constant
Indexed MOV AL, [myArray+ESI] Array base + index
Based MOV AL, [EBX+5] Base register + displacement
Based‑Indexed MOV AL, [EBX+ESI] Base + index
Scaled Indexed MOV EAX, [EBX+ESI*4] For arrays with element size 4 bytes

🔹 Indirect Addressing :: [reg]

MOV EBX, OFFSET myArray
MOV AL, [EBX]        ; reads first element

🔹 Indirect with Displacement :: [reg+disp]

MOV EBX, 1000h
MOV AL, [EBX + 4]    ; reads address 1004h

🔹 Based‑Indexed :: [reg1+reg2]

MOV EBX, OFFSET arr   ; base
MOV ESI, 2            ; index
MOV AL, [EBX + ESI]   ; arr[2]

🔹 Scaled Indexed for 32‑bit arrays

MOV EBX, OFFSET intArray
MOV ESI, 2
MOV EAX, [EBX + ESI*4] ; gets the 3rd element (0‑based) of a DD array

📦 Data Definition Directives

DB  - Define Byte      (1 byte)   → var1 DB 10, 'A', 20h
DW  - Define Word      (2 bytes)  → varW DW 1000, 2000
DD  - Define Doubleword (4 bytes) → varD DD 12345678h
DUP - Duplicate                   → buffer DB 100 DUP (0)

Examples:

.data
    byteArray DB 10, 20, 30, 40          ; four bytes
    wordArray DW 100, 200, 300           ; three words (6 bytes)
    doubleArray DD 1, 2, 3, 4, 5         ; five doublewords (20 bytes)
    zeros DW 50 DUP (0)                  ; 50 words initialized to zero
    pattern DB 4 DUP (1, 2)              ; 1,2,1,2,1,2,1,2 (8 bytes)

📊 Arrays & Traversal with ESI, EDI, EBX

An array is a contiguous memory block of same‑sized elements.

.data
myBytes DB 10h, 20h, 30h, 40h, 50h
.code
MOV ESI, OFFSET myBytes   ; ESI points to first element
MOV AL, [ESI]             ; AL = 10h
MOV AL, [ESI+2]           ; AL = 30h

Common register roles:

  • ESI (Source Index) – usually points to source array
  • EDI (Destination Index) – points to destination array
  • EBX (Base) – holds start address
  • ECX – loop counter

🔸 Two‑dimensional array example (3 rows × 2 columns of bytes)

matrix DB 1,2, 3,4, 5,6
row_size = 2
MOV EBX, OFFSET matrix
MOV ESI, 1               ; row 1 (0‑based)
MOV EDI, 0               ; column 0
MOV AL, [EBX + ESI*row_size + EDI]  ; AL = 3

🎯 Pointer vs Value

Pointer = memory address (e.g., 1000h).
Value = the actual content stored at that address (e.g., 42). 

LEA EBX, myVar   ; EBX = address of myVar (pointer)
MOV ECX, [EBX]   ; ECX = value stored at that address
💡 When passing an array to a function, we pass a pointer (the starting address) instead of copying the entire array. This saves time and memory.

🧪 Lab · Reverse an Array In‑Place

Task: Using only registers and indirect addressing modes, reverse an array of 5 integers (32‑bit) in the same memory (in‑place). No extra memory allowed.

Idea: Use two pointers – ESI at the start, EDI at the end. Swap values, move them toward each other until they meet.

Challenge

  • Change the array to DW (words) and update offsets accordingly (ADD ESI, 2, (size-1)*2).
  • Reverse an array of bytes (DB) using AL and BL.
  • Make the array size flexible: ask the user for the size and values (bonus).
