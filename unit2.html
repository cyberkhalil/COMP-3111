Unit 2: From C to Assembly — First Low-Level Programs

💻 Introduction

High-level languages like C/C++ are human-readable, but CPUs only execute machine instructions. Assembly is the bridge between both worlds.
Understanding this mapping helps you: understand compilers, optimize performance, and debug low-level issues.

🎯 Learning Outcomes

Convert C code to Assembly logic
Use MASM structure (.data / .code / END)
Understand MOV, ADD, SUB, INC, DEC
Understand addressing modes
Build 32-bit programs
Debug using VS Code tools

🔄 Compilation Process

C Code → Compiler → Assembly → Machine Code → EXE
Example:
x = 5; x = x + 2;
MOV EAX, 5 ADD EAX, 2
---

🧠 Conditions in Assembly

There is no "if" in CPU. It uses CMP + jumps.
CMP EAX, EBX JE EqualLabel
CMP affects flags, not values.
---

🔁 Loops

Loops are created using counters + conditional jumps.
MOV ECX, 5 LoopStart: DEC ECX JNZ LoopStart
---

⚙️ MASM Overview

MASM = Microsoft Macro Assembler
Converts assembly → object code
Supports x86 programming
Used for low-level applications
---

📦 Program Structure

.data variables here .code instructions here END main
