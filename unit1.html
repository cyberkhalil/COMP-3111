Chapter 1: Foundations & Visual Simulation (emu8086)

16-bit Architecture • Registers • Flags • Loops • Hardware Mapping

1. Introduction

At the lowest level, all computer operations are executed as machine instructions inside the CPU. Assembly language allows direct control over registers, memory, and processor behavior.

This unit uses emu8086 to visually simulate CPU execution step-by-step.

2. Learning Outcomes

Understand assembly → machine code translation
Use registers (AX, BX, CX, DX)
Execute MOV, ADD, SUB
Analyze CPU flags
Build loops and conditions
Debug using emu8086
Implement Bubble Sort in Assembly

3. What is a Microprocessor? 🧠

CPU executes:
  • Fetch instruction
  • Decode instruction
  • Execute instruction
  • Store result

4. Assembly Language💻

Assembly is a low-level language where each instruction maps directly to CPU operations.
MOV AX, 5 ADD AX, 3

5. 8086 Architecture

ALU: arithmetic & logic
Control Unit: instruction execution
Registers: fast storage
Buses: data transfer

6. ALU

ALU performs arithmetic and logic operations.
MOV AX, 10 SUB AX, 10

Result: AX = 0 → ZF = 1

7. General Purpose Registers

Register Purpose
AX Accumulator
BX Base
CX Counter
DX Data

8. Segment Registers

Register Purpose
CS Code Segment
DS Data Segment
SS Stack Segment
ES Extra Segment
Physical Address = (Segment × 16) + Offset

9. Instruction Pointer

IP holds the address of the next instruction.

10. Instructions 🧾

MOV AX, 5 MOV BX, AX
ADD AX, 3 SUB AX, 1

11. Processor Flags 🎯

ZF = Zero Flag
SF = Sign Flag
CF = Carry Flag
OF = Overflow Flag
MOV AX, 5 SUB AX, 5

Result = 0 → ZF = 1

12. CMP Instruction

CMP compares values without storing result, only affects flags.
CMP AX, BX

13. Loops

MOV CX, 5 L1: DEC CX JNZ L1

14. emu8086 Simulator

Allows visualization of:
  • Registers
  • Memory
  • Flags
  • Execution flow

15. Bubble Sort

Bubble sort compares adjacent elements and swaps them if needed.
CMP AL, [SI+1] JBE Skip XCHG AL, [SI+1] MOV [SI], AL Skip:

16. Lab Exercise 🧪

Implement Bubble Sort on a byte array and observe CPU flags during execution using emu8086.
array DB 7, 3, 9, 1, 5
