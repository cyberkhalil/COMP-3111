🔍 Why Learn Assembly?

Assembly language gives you complete visibility into the processor. Every high‑level instruction (like if, for) becomes a sequence of moves, compares, and jumps. As a cybersecurity engineer, you will use it to:

  • 🔬 Analyze malware at the lowest level
  • 🧱 Understand memory & stack vulnerabilities
  • 🛠️ Build tiny, efficient programs
  • 📊 See exactly how hardware reacts to code
💡 emu8086 is your visual laboratory – it shows the CPU, registers, memory and buses as if they were real electronic components.

⚙️ Installing & Setting Up emu8086

  1. 📥 Download from emu8086.com and install.
  2. 🖥️ The main window contains:
    • 📝 Code editor
    • 📊 Emulator window (registers, flags, memory)
    • ▶️ Step Into (F7) and Run buttons
  3. ✅ After installation, open the sample “Hello World” to test.

🧩 8086 Architecture – Visual Overview

The 8086 is a 16‑bit processor. Below are its core registers that you will manipulate directly.

🔹 General‑Purpose Registers

AX (Accumulator) – arithmetic & data
BX (Base) – memory base address
CX (Count) – loop counter
DX (Data) – extra operand / I/O

📌 Each 16‑bit register splits into high/low 8‑bit parts: AH/AL, BH/BL, etc.

🔹 Segment Registers & Pointers

  • 📂 CS, DS, SS, ES – define memory segments.
  • 📍 IP (Instruction Pointer) – next instruction address.
  • 📌 SP, BP, SI, DI – stack and index pointers.

🚩 Flags Register

After arithmetic/logic operations, these flags change:

  • ZF (Zero) – result = 0
  • SF (Sign) – negative result (bit 7)
  • CF (Carry) – carry out / borrow
  • OF (Overflow) – signed overflow
👀 In the emulator, watch these flags update live after each instruction.

⚡ Assembly → Machine Code → Circuits

Take the simple instruction:

MOV AX, 5

The assembler converts it to opcode B8 followed by two bytes for 5. The processor then:

  1. 📥 Fetches the opcode from memory (address in IP).
  2. 🧠 Control Unit decodes: “move immediate to AX”.
  3. 🔗 Sends the value 5 through internal data bus into AX.
  4. ✅ AX updates – you see it in the emulator!

📌 Basic Instructions & Flag Observation

🔹 MOV (Data Transfer)

MOV AL, 10
MOV BL, 20
MOV CL, AL    ; CL = 10

Step through and watch AL, BL, CL change.

🔹 ADD and Overflow

MOV AL, 100
ADD AL, 200   ; AL = 44 (300-256), CF=1, OF=1

After ADD inspect: CF=1 (carry out), OF=1 (signed overflow), ZF=0, SF=0.

🔹 SUB and Zero Flag

MOV AL, 5
SUB AL, 5     ; AL = 0  → ZF = 1

Zero flag becomes 1 – used for conditional jumps.

🔄 Control Flow: Jumps & Loops

🔹 Compare & Conditional Jumps

MOV AL, 10
CMP AL, 10   ; virtual subtraction, ZF=1
JE  label1   ; jump if equal (ZF=1)
JNE label2   ; jump if not equal (ZF=0)

JE is the same as JZ – both check the Zero flag.

🔹 LOOP Instruction

MOV CX, 5
loop_start:
    ; body
    LOOP loop_start   ; CX--, if CX != 0 jump

🖨️ Example: Print 5→1 (DOS interrupt in emu8086)

MOV CX, 5
MOV AH, 2
MOV DL, '5'
print_loop:
    INT 21h
    DEC DL
    LOOP print_loop

🧪 Full Exercise: Bubble Sort with Flag Watching

Sort a byte array in ascending order and observe flags step‑by‑step.

.model small
.data
    array db 5, 3, 8, 1, 2
    n     db 5
.code
main:
    mov ax, @data
    mov ds, ax

    mov cl, n
    dec cl
outer_loop:
    mov si, offset array
    mov ch, cl
inner_loop:
    mov al, [si]
    cmp al, [si+1]
    jbe no_swap
    mov ah, [si+1]
    mov [si], ah
    mov [si+1], al
no_swap:
    inc si
    dec ch
    jnz inner_loop
    dec cl
    jnz outer_loop

    mov ah, 4ch
    int 21h
end main

🔎 While stepping (F7), watch ZF, CF after each CMP. The pass moves the largest value to the end – classic bubble behaviour.

📊 Check the memory window after each pass to see the array gradually sorted.
