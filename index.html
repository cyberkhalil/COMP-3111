Unit 1 Foundations & Visual Simulation (emu8086) emu8086
16‑bit architecture • registers • flags • loops • hardware mapping

Learning Outcomes

  • Understand how assembly mnemonics become machine code and drive the ALU, registers, and buses
  • Explore general purpose registers (AX,BX,CX,DX) and segment registers visually
  • Execute MOV, ADD, SUB and interpret Zero, Sign, Overflow flags
  • Build conditional jumps and loops with CMP, JZ, JNZ
  • Write a simple sorting algorithm entirely in assembly

Core Topics

  • Assembly → Circuits: opcode decoding, control unit, data path
  • General registers, segment registers, instruction pointer
  • Arithmetic & logic operations, flag register effects
  • Control flow: unconditional/conditional jumps, loop construction
  • emu8086 simulation of memory and I/O
Exercise: Implement bubble sort on a byte array and observe flag changes step‑by‑step.
Unit 2 From C to Assembly: Your First Low‑Level Programs MASM / VS Code
High‑level mapping • basic instructions • memory layout • first .exe

Learning Outcomes

  • See how if, for, and while translate into compare and jump sequences
  • Write a simple program using .data, .code, END directives
  • Understand the role of MOV, ADD, SUB, INC, DEC
  • Assemble, link, and run a 32‑bit console application with MASM

Introduction to Assembly

  • High‑level to low‑level: a short walk through compiler output (C → Assembly)
  • First assembly program: "Hello, world" without external libraries
  • Registers vs. memory: immediate, register, direct addressing
  • Basic arithmetic and data movement patterns
  • Setting up MASM + Visual Studio Code
Lab: Write a program that adds three integers and stores the result – then trace it in a debugger.
Unit 3 Data Movement and Addressing Modes MASM
MOV • LEA • pointers • arrays • indirect addressing

Learning Outcomes

  • Master MOV, MOVZX, MOVSX, LEA
  • Use direct, indirect, indexed, and based addressing modes
  • Work with arrays: accessing elements via ESI, EDI, EBX
  • Understand the difference between a pointer and a value

Addressing Deep Dive

  • Immediate vs. register vs. memory operands
  • Indirect operands: [reg], [reg+disp], [reg1+reg2]
  • Array traversal and base‑index addressing
  • Data definition directives: DB, DW, DD, DUP
Lab: Reverse an array in place using only registers and indirect addressing.
Unit 4 Arithmetic, Logic, and the Flags Register MASM
ADD • SUB • MUL • DIV • AND • OR • XOR • shifts

Learning Outcomes

  • Use ADD, SUB, INC, DEC with carry and overflow awareness
  • Multiply and divide with MUL/IMUL and DIV/IDIV
  • Apply bitwise AND, OR, XOR, NOT for masking and toggling
  • Shift and rotate: SHL, SHR, SAL, SAR, ROL, ROR
  • Read the flags register after each operation

Flag‑Driven Logic

  • Zero flag (ZF), Sign flag (SF), Overflow flag (OF), Carry flag (CF)
  • Conditional jumps based on flags: JE, JNE, JG, JL, etc.
  • Implementing high‑level conditions with flag‑based branching
  • Converting number bases (Bin ↔ Hex ↔ Dec) using logic ops
Exercise: Build a simple calculator that reads two digits, performs an operation, and displays the result.
Unit 5 Control Flow, Procedures, and the Stack MASM
CMP • JMP • LOOP • CALL/RET • stack frames • prologue/epilogue

Learning Outcomes

  • Construct all common loop patterns with LOOP, JMP, and conditional jumps
  • Define and call procedures using CALL and RET
  • Pass parameters via registers and the stack
  • Write proper prologue (push ebp / mov ebp, esp) and epilogue
  • Understand call conventions (cdecl, stdcall) at the assembly level

The Stack in Action

  • Stack operations: PUSH, POP, PUSHAD, POPAD
  • Local variables and stack frames
  • Recursive procedures and stack limits
  • Nested procedure calls and preserving registers
Lab: Implement a recursive factorial function and trace stack changes in x64dbg.
Unit 6 Strings, Input/Output, and Operating System Interface Irvine32
string primitives • console I/O • Windows API basics

Learning Outcomes

  • Use string instructions: MOVSB, STOSB, LODSB, CMPSB
  • Perform console I/O with Irvine32 (ReadString, WriteString, WriteInt)
  • Read and write text files using Irvine32 file functions
  • Call a simple Windows API function (MessageBoxA, ExitProcess) from assembly

Bridging to the OS

  • Irvine32 library: keyboard, display, file operations
  • String manipulation and parsing
  • Introduction to Windows API calling convention
  • Building a complete interactive console application
Mini Project: Create a text‑based menu program that encrypts/decrypts a string using a simple XOR cipher.
Unit 7 Reverse Engineering & Dynamic Analysis (x64dbg) x64dbg
disassembly • breakpoints • C-to-Asm patterns • patching

Learning Outcomes

  • Navigate the x64dbg interface: CPU view, hex dump, memory map
  • Set software/hardware breakpoints and step through code
  • Recognize compiler patterns for if‑else, loops, and function calls
  • Analyze function arguments and return values from disassembly
  • Apply basic patching (e.g., change JZ to JMP) to alter program behavior

Ethical Analysis

  • Dynamic debugging vs. static disassembly
  • Identifying hardcoded credentials and license checks
  • Patching techniques and binary modification
  • Legal and ethical boundaries: analysis for defense only
Challenge: Given a crackme.exe, locate the password check routine and patch it to accept any password.
