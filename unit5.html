Unit 5 — Control Flow, Procedures, and the Stack

Programs require decision-making, loops, reusable procedures, and structured memory management. Assembly provides this through jumps, comparisons, calls, and stack operations.

1. Introduction

Program flow in assembly is not linear in real applications. It is controlled using conditional logic, loops, procedure calls, and stack operations.

🔁 Loops (repeat execution)
🔀 Branching (decision making)
📞 Procedures (reusable code)
📚 Stack (memory management)

2. Control Flow

By default, CPU executes instructions sequentially. Control flow instructions modify execution order.

  • Comparisons
  • Conditional jumps
  • Loops
  • Procedure calls

3. CMP Instruction

CMP compares two values using subtraction without storing the result. 

CMP EAX, EBX
Flags are updated based on comparison result.

4. Conditional & Unconditional Jumps

Instruction Meaning
JE Jump if equal
JNE Jump if not equal
JG Jump if greater
JL Jump if less
JZ Jump if zero
JNZ Jump if not zero
JMP Unconditional jump 
CMP EAX, EBX
JE EqualLabel

5. Loops

Loops repeat execution until condition becomes false.

MOV ECX, 5

LoopStart:
DEC EAX
LOOP LoopStart
LOOP automatically decrements ECX until it reaches zero.

6. Procedures

Procedures are reusable blocks of code.

  • Code reuse
  • Modularity
  • Cleaner structure
MyProcedure PROC
MOV EAX, 5
RET
MyProcedure ENDP

CALL: pushes return address and jumps

RET: returns execution

7. Stack

The stack is LIFO (Last In First Out).

PUSH EAX
POP EBX
📥 PUSH → add to stack
📤 POP → remove from stack
⬇ Stack grows downward
📍 ESP points to top

8. Stack Frames

Used to manage function execution context.

PUSH EBP
MOV EBP, ESP
SUB ESP, 8
Stack frame contains: parameters, return address, local variables.

9. Recursion

Functions that call themselves (e.g., factorial, Fibonacci).

CMP EAX, 1
JLE Done

PUSH EAX
DEC EAX
CALL Factorial

POP EBX
MUL EBX
Recursion uses stack heavily → risk of stack overflow.
