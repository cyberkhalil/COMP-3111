Unit 5: Control Flow, Procedures, and Stack

Introduction

Programs are not just sequential instructions. They require decision-making, loops, reusable procedures, and structured memory management.

The stack is a core CPU structure used for procedure calls, local variables, and return addresses.
  • Branching (JMP, CMP)
  • Loops (LOOP, JNZ)
  • Procedures (CALL / RET)
  • Stack operations (PUSH / POP)

Control Flow

Processors normally execute instructions sequentially, but control flow changes execution order.

CMP Instruction

CMP EAX, EBX

CMP compares values and updates flags without storing result.

Conditional & Unconditional Jumps

JE Equal JNE NotEqual JG Greater JL Less JMP Start

Jumps control execution based on flag results.

Loops

MOV ECX, 5 LoopStart: DEC EAX LOOP LoopStart

LOOP automatically decrements ECX until it reaches zero.

Procedures

Procedures are reusable blocks of code that improve modularity.
MyProc PROC MOV EAX, 5 RET MyProc ENDP

Stack Operations

  • PUSH → add data to stack
  • POP → remove data from stack

Stack follows LIFO (Last In First Out).

Stack Frames

Stack frames store parameters, return addresses, and local variables.
PUSH EBP MOV EBP, ESP SUB ESP, 8

This creates a structured function environment.

Recursion

Recursive procedures call themselves (e.g. factorial, Fibonacci).

Factorial PROC CMP EAX, 1 JLE Done PUSH EAX DEC EAX CALL Factorial POP EBX MUL EBX Done: RET Factorial ENDP
